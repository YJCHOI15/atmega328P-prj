# ATmega328P 기반 스마트 비데 시스템

본 프로젝트는 경북대학교 '피카츄' 팀(전자공학부 한석민(4), 김수연(4), 이수형(4), 최용진(3))이 협력하여 구현한 2024 COSS 차세대반도체 MCU 응용 경진대회 본선 진출을 위한 예선 작품입니다. 

ATmega328P 마이크로컨트롤러와 다양한 센서 및 액추에이터를 사용하여, 사용자의 편의성과 에너지 효율을 극대화한 지능형 맞춤 비데 시스템을 설계하고 구현하였습니다.

---

## 1. 프로젝트 개요

본 프로젝트는 ATmega328P MCU를 핵심 제어 장치로 사용하여 현대적인 비데의 기능들을 구현합니다. 

직관적인 버튼 인터페이스를 통해 온도, 수압, 노즐 위치 등 다양한 맞춤 설정 기능을 제공합니다. 

핵심 기능으로는 압력 센서를 이용한 자동 절전 모드, EEPROM에 저장되는 사용자 맞춤 프로필, 그리고 수위 감지를 통한 안전 기능 등이 포함됩니다.

---

## 2. 담당 역할

**절전 모드 및 물 채움 모드 개발 담당:** 

  * 압력 센서(FSR402)와 수위 센서(SZH-EK057)의 ADC 값을 기반으로 시스템의 상태(절전/활성, 물 채움)를 전환하는 핵심 로직을 구현했습니다. 특히, Timer2 인터럽트를 활용하여 다른 기능에 영향을 주지 않는 비동기(non-blocking) 방식의 LED 깜빡임 기능을 설계하고 구현했습니다. (구현 내용은 yongjin.c 파일에 포함됨)

--- 

## 3. 주요 기능

스마트 비데 시스템은 다음과 같은 핵심 기능들을 포함합니다:

1. **물 분사 (세정):** 사용자가 스위치를 눌러 활성화하는 핵심 세정 기능입니다.

2. **건조 기능:** 사용 후 팬을 작동시켜 건조를 시작합니다. 

3. **절전 모드 (Sleep Mode):** 압력 센서를 통해 사용자가 앉아있지 않음을 감지하면, 시스템은 최소 전력 모드로 진입하여 에너지 소비를 줄입니다. 

4. **시트 온도 조절:** 캡톤 필름 히터를 이용하여 변기 시트 온도를 3단계(상, 중, 하)로 조절할 수 있습니다.

5. **물 온도 조절:** 물탱크의 물 온도를 3단계로 조절하여 따뜻한 물을 제공합니다. 

6. **수압 조절:** 스텝 모터로 노즐 분사 각도를 미세 조정하여 수압을 3단계로 조절합니다. 

7. **노즐 위치 조절:** 사용자에 맞춰 노즐의 위치를 3단계(전, 중, 후)로 조절할 수 있습니다. 

8. **자동 물내림:** 사용자가 일어서면 압력 센서가 이를 감지하여 서보 모터로 자동으로 물을 내립니다. 

9. **사용자 맞춤형 모드:** 여러 사용자의 수압, 온도, 노즐 위치 설정을 EEPROM에 저장하고 불러올 수 있습니다. 

10. **수위 감지:** 물탱크의 수위를 감지하여 물이 부족할 경우 분사 및 히터 기능을 중지하고, LED를 깜빡여 사용자에게 알립니다.

## 4. 소프트웨어 및 구현 상세

펌웨어는 C언어로 작성되었으며 ATmega328P에 직접 프로그래밍되었습니다. 주요 소프트웨어 모듈은 다음과 같습니다.

**절전 모드 (압력 센서 기반)**

  * **구현:** 압력 센서(FSR402)를 외부 인터럽트 핀(INT0)에 연결하여 구현했습니다.

  * **로직:**

    1. 사용자가 앉으면 압력 변화가 감지되어 인터럽트가 발생하고, MCU가 Power-down 절전 모드에서 즉시 깨어납니다.

    2. 사용자가 일어나면 다시 인터럽트가 발생하고, 타이머(Timer1)가 시작됩니다.

    3. 타이머가 5분에 도달하면 Sleep_enter() 함수가 호출되어 MCU를 가장 깊은 절전 모드인 Power-down 모드로 전환합니다.

**수위 감지 및 물 채움 모드**

  * **구현:** 수위 센서를 ADC 핀에 연결하고, 시각적 피드백을 위해 Timer2를 사용했습니다.

  * **로직:**

    1. check_water_level 함수가 지속적으로 센서 값을 읽습니다.

    2. 값이 WATER_THRESHOLD 이하로 떨어지면 water_refill_mode가 활성화됩니다.

    3. 이 모드에서는 물 분사가 중지(stop_water_spray())되고 경고 LED가 깜빡입니다.

    4. LED 깜빡임은 Timer2의 CTC 모드와 비교 일치 인터럽트(ISR(TIMER2_COMPA_vect))를 사용하여 비동기(non-blocking) 방식으로 구현되었습니다.

## 5. 어려움 및 한계점

프로젝트 개발 과정에서 다음과 같은 문제점들이 발생했습니다:

**건조 기능 (DC 모터):** 건조용 DC 모터가 작동할 때 높은 순간 전류를 소모하여 전체 시스템이 순간적으로 셧다운되는 문제가 발생했습니다. 최종 시연에서는 릴레이와 LED를 이용해 모터 동작을 표현하는 것으로 대체했습니다.


**절전 모드 (5분 대기):** 압력 센서의 변화 감지 후 5분간 대기했다가 절전 모드로 진입하는 기능은 타이머 중첩 문제로 인해 최종적으로 구현하지 못했습니다.


**기능 통합 문제 (물 채움 및 히팅 기능):** 수위 감지 및 히팅 기능은 개별적으로 테스트했을 때는 정상 동작했으나, 전체 시스템에 통합한 후 간헐적으로 오작동하는 문제가 발생했습니다.
